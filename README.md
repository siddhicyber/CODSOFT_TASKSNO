# CODSOFT Cyber Security Internship Tasks

## Overview

This repository contains all the projects completed during the **CODSOFT Cyber Security Internship**.
The tasks focus on practical cybersecurity concepts including network analysis, phishing awareness, secure coding, intrusion detection, and secure file sharing.

## Completed Tasks

## Task 1: Network Packet Analyzer

**Description:**
A Python-based network packet analyzer that captures and analyzes network traffic.

**Features:**

* Captures network packets
* Displays source and destination IP addresses
* Identifies protocols
* Provides packet information

**Technologies Used:**

* Python
* Scapy

---

## Task 2: Phishing Awareness Training

**Description:**
A cybersecurity awareness presentation explaining phishing attacks and prevention techniques.

**Topics Covered:**

* Introduction to phishing
* Types of phishing attacks
* Common phishing methods
* Prevention and safety practices

**Technology Used:**

* PowerPoint Presentation

---

## Task 3: Secure Code Review

**Description:**
A security review of application source code to identify vulnerabilities and improve coding practices.

**Activities Performed:**

* Analyzed source code
* Identified security weaknesses
* Used static code analysis tools
* Suggested secure coding improvements

**Technologies Used:**

* Python
* Bandit Security Scanner

---

## Task 4: Network Intrusion Detection System

**Description:**
Implemented a network intrusion detection system to monitor suspicious network activities.

**Features:**

* Configured intrusion detection rules
* Monitored network traffic
* Detected suspicious activities

**Technology Used:**

* Snort

---

## Task 5: Secure File Sharing System

**Description:**
A secure file sharing application developed to provide protected file upload and download functionality.

**Features:**

* User authentication
* Secure file upload
* Secure file download
* File protection mechanisms

**Technologies Used:**

* Python
* Flask
