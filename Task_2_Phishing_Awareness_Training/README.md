# Task 2: Phishing Awareness Training

## Project Description
This project is a phishing awareness training presentation created to educate users about phishing attacks, common techniques used by attackers, warning signs of phishing emails, and methods to stay protected online.

## Objective
- Understand phishing attacks.
- Identify phishing emails and websites.
- Learn safe online practices.
- Improve cybersecurity awareness.

## Topics Covered
- Introduction to Phishing
- Types of Phishing Attacks
- Common Warning Signs
- Real-World Examples
- Prevention and Protection Tips

## Tools Used
- Microsoft PowerPoint

## Outcome
The presentation helps users recognize phishing attempts and follow security best practices to avoid becoming victims of cyber attacks.
