# Task 2: Phishing Awareness Training

## Project Description

This project is a Phishing Awareness Training presentation created to spread awareness about phishing attacks, their techniques, and prevention methods.

## Objective

- Understand phishing attacks and their impact.
- Learn different types of phishing techniques.
- Identify suspicious emails, links, and messages.
- Promote safe online practices.

## Topics Covered

- What is Phishing?
- Types of Phishing Attacks
- Common Phishing Techniques
- Signs of Phishing Attempts
- Prevention and Safety Measures

## Tools Used

- Microsoft PowerPoint

## Outcome

Created a cybersecurity awareness presentation to educate users about phishing threats and ways to stay protected.
