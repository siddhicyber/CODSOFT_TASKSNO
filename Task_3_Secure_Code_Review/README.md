# Task 3: Secure Code Review

## Project Description
This project focuses on reviewing source code to identify security vulnerabilities and coding flaws. Static code analysis and manual review techniques were used to detect security issues and recommend secure coding practices.

## Objective
- Identify security vulnerabilities in source code.
- Analyze insecure coding practices.
- Suggest remediation techniques.
- Improve application security.

## Tools Used
- Python
- Bandit (Static Code Analysis Tool)
- Visual Studio Code

## Security Issues Identified
- Hardcoded credentials
- Weak input validation
- Insecure coding practices

## Recommendations
- Use secure password handling.
- Validate all user inputs.
- Follow secure coding standards.
- Perform regular security testing.

## Outcome
The code review helped identify vulnerabilities and improve the overall security of the application.
